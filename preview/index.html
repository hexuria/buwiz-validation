eBIRForms Preview

The official BIR form HTAs from this repository, opened in an ordinary browser. The HTA files are BIR's, unmodified. The viewer adds a stand-in for the Internet Explorer APIs they call. Saving, printing to file, the TIN check digit (chkt.exe), encryption and submission need Windows, so they are stubbed. Layout, fields, dropdowns loaded from the reference XML and the JavaScript validation all run.
